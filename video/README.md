# Demo film

The film is generated from code: scripted narration, HTML motion graphics, a recording of the real studio, and
ffmpeg. No video editor, and nothing is sped up. Output: `video/out/redline-demo.mp4`.

| Step | Tool | Output |
| --- | --- | --- |
| Script | `video/script.md` | one table row per scene: on-screen content and narration |
| Voice | `python video/narrate.py` (edge-tts, `en-US-AndrewNeural`) | `video/vo/NN.wav`, `NN.txt` |
| Motion graphics | `video/scenes/scenes.html?scene=<id>` | six scenes in the product's palette and fonts |
| Render scenes | `node video/render_all.mjs` (Playwright, installed Edge) | `video/renders/sNN.webm` |
| Product capture | `node video/capture_demo.mjs` | `video/renders/capture_<beat>.webm`, `video/assets/demo.json` |
| Music | `video/music.py` (numpy) | a generated ambient bed, no download |
| Assemble | `python video/assemble.py` (ffmpeg) | `video/out/redline-demo.mp4` |

## Run order

The app must be running for the capture step (`npm run dev`).

```bash
python video/narrate.py
node video/render_all.mjs
node video/capture_demo.mjs
python video/assemble.py
```

To change one line: edit its row in `script.md`, then `python video/narrate.py 7`, re-render or re-capture that
scene (`node video/render_all.mjs 9`, `node video/capture_demo.mjs edit`), and assemble again.

## What is real

- The product footage is the real studio replaying a session recorded with live `gemma-4-31b-it` calls
  (`video/record_session.ts`, stored in `demo/`). The model's thinking time is cut; the narration says so, and the
  loading panel shows how long each real call took.
- Every number on screen is read at render time: the byte count from `demo/v1/meta.json`, the eval figures from
  `data/eval-results.json`, the test count from `video/assets/tests.txt` (update it from `npx vitest run`).
- The schematic lines in the problem scene are read from `demo/v1/design.kicad_sch`.

## Needs

ffmpeg on the PATH, Python with `edge-tts` and `numpy`, Node with Playwright, and Microsoft Edge. There is no GPU
on the build machine, so the voice is edge-tts, which sends the narration text to Microsoft's speech service.

## Publishing

Title: `Redline — describe a circuit, get a real KiCad schematic`

Description:

```
Redline turns one sentence into a real KiCad schematic, checks it with KiCad's own rule check, and lets you
change it or question it by chat. Gemma 4 writes a small list of parts and connections; code draws everything.

Repo: https://github.com/thegoodengineer/redline
Runs locally (needs KiCad 10); there is no hosted demo.

Model: Gemma 4 (gemma-4-31b-it) through the Gemini API.
Voice: Microsoft edge-tts (en-US-AndrewNeural). Music: generated by video/music.py, no third-party track.
Fonts: Geist and Geist Mono (SIL Open Font License). No stock photos or footage.
```
